# Payroll Management API

A payroll management module developed as part of a collaborative HR Management Platform.

## Features

- **Payroll Calculation:** Calculate employee payroll for a specified pay period.
- **Deduction Management:** Correct employee deductions before payroll finalization.
- **Payroll Review & Finalization:** Review and finalize payroll records.
- **Payment Management:** Update payment status and payment dates.
- **Payslip Management:** Retrieve individual and bulk payslips.
- **Payroll History:** Retrieve previous payroll records.
- **Role-Based Access:** Separate admin payroll operations from employee payslip access.

## Technologies

- Node.js
- Express.js
- JavaScript
- MongoDB
